Connexions numerades, material, errors freqüents, programes i registres per convertir els reptes de Circuita en pràctiques d’aula.

Què està contrastat? S’han revisat les làmines originals i una activitat tècnica amb autoria d’Academia de Inventores. Els esquemes derivats i els programes són propis. No s’ha fet la prova amb el vostre maletí: compara les inscripcions i fes el muntatge tu abans de la sessió.

La preparació que has de completar una vegada

  1. Identifica els mòduls per nom, símbol i marques dels terminals.
  2. Comprova piles, cables i components amb M0.
  3. Fes M1/M2 per preparar primària i M5 abans de programar.
  4. Si faràs servir el sensor, completa M6 i el calibratge.
  5. Prepara l’organització de grups i l’evidència individual.

Pla d’aula, 40 sessions orientatives, rols i plantilles imprimibles →

Un únic maletí pot servir amb estacions. No cal comprar material abans de fer inventari. Motor, servo i brunzidor no són necessaris per a aquests quinze reptes; s’incorporen només amb documentació específica i una nova prova docent.

Fitxa de muntatge

Prepara l’ordinador i comprova la càrrega

  1. Fes servir un cable USB de dades. Comprova el tipus de connector del teu controlador.
  2. A Hello, Blocks!, selecciona Cirkids a la tria de placa si aquesta opció és disponible. Connecta, selecciona el dispositiu adequat i carrega una primera sortida. L’aspecte de la interfície pot canviar.
  3. Els guions de blocs de cada fitxa s’han de reconstruir dins de l’editor: no són un format nadiu importable. Especifica els pins d’aquesta fitxa i revisa el codi generat.
  4. Alternativament, obre cada fitxer .ino a Arduino IDE. Cada programa té la seva carpeta del mateix nom. Per al controlador compatible UNO documentat, selecciona Arduino Uno i el port identificat. Si el dispositiu difereix, consulta’n la documentació.
  5. Carrega primer 00_Prova_LED. Per al sensor, 01_Calibratge i monitor a 9600 bauds. Tanca altres monitors sèrie abans de tornar a carregar.
  6. No cal connectar cap placa per estudiar el codi. No es concedeixen permisos USB ni es carrega res automàticament des d’aquest dossier.

Circuits de piles i circuits del controlador USB són recorreguts separats. No uneixis la font de 4,5 V amb el terminal 5V del controlador. Les sortides D10/D11 no s’uneixen entre si. Les instruccions de LED a pin digital són exclusivament per als mòduls Cirkids documentats; no per a LEDs solts.

Descarrega l’INO de referència
02, 03 i 05 es distribueixen amb CALIBRATED = false. Compilen i mantenen el LED apagat fins que introdueixes les dades reals. Fes servir el calibrador següent per obtenir la versió configurada.
Els set sketches i sis variants calibrades han compilat i enllaçat per ATmega328P/Arduino Uno amb el core Arduino AVR 1.8.8 i AVR GCC 7.3.0. Cap programa s’ha carregat ni provat en un maletí físic durant aquesta preparació. Informe i límits de verificació.


De les lectures reals al model 0–100
Calibra abans de decidir
Amb 01_Calibratge, pren cinc lectures enteres de 0 a 1023 en cadascuna de les dues condicions. Separa-les amb espais, comes o punts i coma. La referència clara és la llum de treball de la maqueta, no una mesura universal.
Encara no s’han introduït les dues sèries de lectures.
El càlcul arrodoneix les mitjanes a enters i retalla el resultat a 0–100. No són lux. Diferència mínima de treball: 20 comptes ADC. Si la separació és petita, revisa el muntatge i la llum, no activis el programa a cegues.


Quan una prova falla
ObservacióRevisa en aquest ordre
Cap pràctica de piles funcionaInventari → piles i activació de la font → M0 → contactes → polaritat. Desactiva abans de modificar.
El programa no es carregaCable de dades → dispositiu/port → placa seleccionada → permisos de l’ordinador → missatge concret d’error. No provis controladors USB a l’atzar.
Carrega però el LED no respon00_Prova_LED → D11 i GND → mòdul/polaritat → absència d’alimentació externa accidental.
Sensor fix o poc variable01_Calibratge → A0 → node N → R 10 kΩ → alimentació → llum de treball. Repeteix les dues sèries.
L’app i la maqueta no coincideixen exactamentDiferencia escala simbòlica i ADC, soroll, brillantor, tensió disponible i detalls no modelats. Registra la diferència; no inventis una coincidència.
Si no hi ha evidència clara, torna a l’últim muntatge que sí funcionava. No augmentis l’alimentació ni retiris resistències per forçar un resultat.
