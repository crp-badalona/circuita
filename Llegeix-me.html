Per començar amb el maletí real

Obre primer Dossier-muntatge.html: completa la preparació, fes M0 i escull la fitxa del repte. El dossier relaciona els quinze reptes amb deu muntatges i set programes a programes/. Mantén tota la carpeta del paquet: les descàrregues de codi i els enllaços depenen d’aquesta estructura. No s’ha provat el vostre maletí físic.

Per al sensor: primer 01_Calibratge; després introdueix les lectures al calibrador i descarrega el programa configurat. Els INO de sensor sense configurar mantenen el LED apagat.

Consulta Organitzacio-aula.md per planificar les sessions, els rols i l’avaluació física.

Com començar

  1. Descomprimeix el paquet en una carpeta.
  2. Obre Circuita.html en un navegador actual. Si tenies la versió anterior oberta, recarrega-la.
  3. Tria «Reptes per etapa» i una de les cinc etapes.
  4. Comença pel repte guiat; després prova el de continuïtat i el de millora.
  5. Per preparar la sessió, obre Guia-professorat.html: ofereix modelatge dels mateixos conceptes amb cinc recorreguts.

Mantén els dos HTML a la mateixa carpeta perquè els enllaços entre app i guia funcionin. Les imatges estan incrustades: no cal connexió per utilitzar els laboratoris. Els enllaços a fonts externes sí que requereixen internet.

Què inclou

  • Circuita.html: 15 activitats amb set passos, peces Cirkids, construcció virtual, autocorrecció, solució visual controlable, rutines de pensament, rúbriques, segon instrument i tiquets de sortida.
  • Guia-professorat.html: bases conceptuals, cinc modelatges, laboratoris, pràctica guiada, preguntes, transferència i reflexió.
  • Guia-professorat.md: versió de consulta completa.
  • Disseny-Circuita.md: document de disseny i evolució; distingeix activitats implementades i banc d’ampliació proposat.

Recórrer un repte

Observa i pensa → tria peces → connecta el model → prediu i manipula → executa els casos → mira la solució → avalua i reflexiona.

Els controls de l’animació són reproduir, pausar, un pas, tornar a l’inici i ajustar la durada del pas. Consultar la solució no repara el teu model: torna a configurar-lo i repeteix les proves. El repte només queda completat virtualment quan el model propi supera els casos.

Les reflexions es poden escriure, explicar oralment o mostrar amb dibuix comentat; el docent pot anotar-ne una síntesi. Els suports d’accés no baixen el nivell de la rúbrica. La diana i els altres instruments no calculen qualificacions automàtiques.

Dades i còpies

El progrés i les notes es desen en aquest navegador si l’emmagatzematge està disponible. No hi ha comptes ni enviament a un servidor. Exporta les evidències per conservar-les. Canviar de navegador, de carpeta o de dispositiu pot impedir recuperar el desament local; no és un sistema de còpia de seguretat ni una plataforma de gestió de classe.

Els noms de llocs situen encàrrecs escolars ficticis en maquetes de Badalona. Els models són qualitatius, no especifiquen pins ni certifiquen connexions físiques del kit. Abans del muntatge real, contrasta el material i el manual amb el docent. No s’utilitza la xarxa domèstica.
